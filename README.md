# TaskFlow - Sistema de Gerenciamento de Projetos  


## 🎯 Objetivo do Projeto

O TaskFlow é um sistema web abrangente projetado para centralizar e otimizar a gestão de fluxos de trabalho e projetos empresariais. O principal objetivo do software é fornecer uma solução simples, organizada e intuitiva para o gerenciamento de tarefas, auxiliando no acompanhamento contínuo de atividades, na colaboração estruturada entre equipes e na melhoria da produtividade geral.  A plataforma atua no controle de ponta a ponta das operações, permitindo o planejamento detalhado de cronogramas e o estabelecimento de marcos importantes. O software foi idealizado para mitigar problemas sistêmicos frequentes na execução de projetos, como o atraso no cumprimento de prazos e as falhas de comunicação.  Para garantir um ambiente de trabalho mais eficiente, o TaskFlow facilita a divisão clara de responsabilidades e centraliza todas as informações essenciais em uma única interface integrada. O sistema alcança isso ao suportar três perfis de acesso distintos (Project Manager, Colaborador e Cliente), garantindo o controle gerencial completo, o acompanhamento operacional diário por parte da equipe e um canal de comunicação direto e transparente com os clientes ao longo de todo o ciclo de vida do projeto.

## 📚 Contextualização da Matéria de Engenharia de Software

Este projeto foi desenvolvido como parte integrante e requisito avaliativo da disciplina de Engenharia de Software, no Departamento de Computação da Universidade Federal de Sergipe. O projeto visa transcender o embasamento teórico, proporcionando um ambiente real para a aplicação prática dos conceitos fundamentais de todo o ciclo de vida de um software.
O foco principal desta atividade foi compreender, na prática, como transformar uma ideia abstrata e necessidades de negócio em uma solução de software totalmente funcional, organizada e de fácil uso. Para isso, o TaskFlow serviu como um caso prático onde foram aplicadas metodologias completas de análise e projeto.

A execução abrangeu as seguintes etapas críticas da engenharia:
- Levantamento rigoroso e especificação de requisitos funcionais, não-funcionais, de interface e de domínio, guiados pelas normas do padrão IEEE 830/1998.
- Planejamento arquitetural do sistema web, modelagem de dados e estruturação do desenvolvimento orientado a objetos.
- Aplicação de boas práticas de versionamento, integração contínua, estruturação de testes e manutenção de sistemas.

Dessa forma, a documentação produzida e o código implementado refletem o esforço da equipe em consolidar as melhores práticas da Engenharia de Software, criando uma base sólida para a construção de sistemas que resolvem problemas reais de gestão e produtividade.
